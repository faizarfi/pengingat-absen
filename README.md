# ⏰ Pengingat Absensi Otomatis (WhatsApp & Telegram)

Sistem pengingat absensi otomatis (jam masuk dan pulang kerja) terintegrasi dengan **WhatsApp Desktop Agent (Anti-Ban & Direct Hardware Keystroke)**, **Bot Telegram Admin**, kalender hari libur nasional, dan **Dashboard Web Admin**.

   - Daftar software yang dibutuhkan (PHP, Composer, Node.js, Python, WhatsApp Desktop).
   - Cara setup database, `.env`, migrasi, dan seeder.
   - Cara menjalankan sistem cukup 1-klik (`START-ALL.bat`).
   - Troubleshooting masalah umum.

2. ☁️ **[Panduan Hosting VPS & Komputer Agent Kantor](file:///c:/Users/USER/pengingat-absen/PANDUAN_HOSTING_VPS_DAN_AGENT.md)**
   - Setup Web Dashboard di Server VPS / Cloud Linux.
   - Mengarahkan WA Desktop Agent di PC kantor ke server VPS.
   - Setup Webhook Telegram Bot 24 Jam.
